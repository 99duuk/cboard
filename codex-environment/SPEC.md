- 관리 단위: 이름 있는 Codex 실행 프로필
- 사용자 표시 명칭: 계정
- 구성: 등록 이름·실행 별칭·독립 홈·설정·로그인 상태
- 등록 이름과 실제 로그인 신원의 구분
- 사용자별 이름·개수·모델 선택의 자유
- 동일 로그인 신원의 복수 프로필 허용 및 중복 안내
- 신원 확인 실패의 미확인 표시, 추측 신원 표시 금지
- NVM과 유사한 등록·목록·선택·기본값·실행·해제 사용 방식
- 특정 사용자·기존 5개 계정·iTerm 프로필에 대한 필수 의존 제거
- 현재 Mac의 기존 인증·세션·기록·모델 차이·계정 명령 보존
- Windows·Linux·GUI·데몬·자동 계정 라우팅·한도 우회 제외
- 원격 계정 삭제·인증 복제·로컬 데이터 영구 삭제 제외

## 3. 선택과 실행

### 3.1 우선순위

1. `crun <이름>` 또는 계정별 실행 별칭
2. 외부에서 명시한 `CODEX_HOME`
3. 현재 셸의 `cuse` 선택
4. 저장된 `cdefault` 기본값
5. 선택 없음

### 3.2 셸 의미

- `cuse <이름>`의 현재 셸 및 이후 자식 셸 적용
- 다른 터미널·이미 실행 중인 세션에 대한 영향 없음
- `cuse --clear`의 셸 선택 해제 및 기본값 재사용
- `cdefault <이름>`의 이후 새 셸 적용, 기존 셸 선택 유지
- `cdefault --clear`의 저장 기본값 해제
- 외부 `CODEX_HOME` 존재 시 `cuse`의 충돌 안내 및 중단
- `ccurrent`의 대상·홈·선택 근거 표시
- 미등록 외부 홈의 명시적 사용과 미등록 기본 홈의 암묵적 사용 구분
- 미선택 관리형 `codex`의 실행 중단 및 등록·선택 안내
- 삭제된 선택·별칭의 실행 직전 등록 유효성 재검사

### 3.3 기존 환경 호환

- 현재 설치의 최초 업그레이드에 한정한 기존 `codex` 기본값 보존
- 빈 설치·일반 배포의 계정 자동 등록 및 기본값 자동 지정 없음
- 기존 홈의 명시적 가져오기를 통한 기본 환경 유지
- 기존 `CODEX_HOME`·셸 함수·별칭 충돌의 사전 표시
- 알 수 없는 사용자 셸 코드의 자동 삭제 금지
- 원래 CLI 실행 파일 직접 호출 경로의 보존

### 3.4 프로세스 계약

- `crun personal "작업 내용"` 및 `crun personal -- --help` 지원
- 일회 실행의 현재 선택·기본값 변경 없음
- 인자·표준 입출력·신호·Codex 종료 코드 보존
- 계정 홈의 실행 자식 프로세스 한정 전달
- iTerm 설치 시 선택적 표시 기능, 다른 터미널의 정상 실행

## 4. 등록과 로그인

### 입력

- `cnew`의 대화형 이름·별칭 입력
- `cnew personal`의 기본 별칭 `cpersonal`
- `--alias`·`--no-login`·`--dry-run` 지원
- 기본 홈: `~/.codex-<이름>`, 이름 `codex` 포함
- 이름 `codex`의 기본 별칭 `ccodex`
- 신규 실행 별칭 `codex`의 예약 및 기존 등록 별칭 호환 보존
- 비대화형 실행의 이름 필수 및 입력 대기 금지
- 이름·별칭·홈의 중복·예약어·보호 경로·중첩 경로 검사
- 기존 홈 발견 시 신규 생성 중단 및 가져오기 안내

### 처리 순서

1. 입력·의존성·충돌 사전 확인
2. 등록부·계정 원본·홈·공유 연결의 복구 가능한 적용
3. 계정별 도구 활성화
4. 공식 로그인
5. 공식 신원 확인
6. 완료 단계·미완료 단계·재시도 명령 표시

| 상황 | 결과 |
| --- | --- |
| 사전 확인 실패 | 변경 없음 |
| 등록 적용 실패 | 적용 변경 복구 또는 복구 필요 상태 표시 |
| 도구 활성화 실패 | 등록 유지·로그인 진행·실패 항목 표시 |
| 로그인 취소 | 등록 유지·미로그인 표시·종료 코드 130 |
| 로그인 성공·신원 확인 실패 | 등록 유지·신원 미확인·재확인 안내 |
| 동일 이름 재실행 | 기존 등록 보존·상태 및 재시도 방법 안내 |

- `--no-login`의 등록·도구 활성화만 수행
- `--dry-run`의 파일 변경·도구 설치·로그인 없음
- 첫 계정의 기본값 자동 지정 없음 및 지정 방법 안내
- 안전한 신규 계정 기본값의 독립 원본
- 기존 다른 계정의 모델·승인·샌드박스 정책 복제 금지
- `clogin`의 공식 로그인 및 토큰 값 출력 금지

```sh
cenv account import personal --home ~/.codex-existing
```

- 기존 인증·설정·세션·기록 보존
- 가져온 홈의 외부 소유 자원 표시
- 동일·중첩 홈의 중복 등록 차단
- 기존 값과 공통 관리 키의 차이 사전 표시
- 충돌 시 기본 중단, 명시적 해소 후 적용
- `--adopt-existing`의 충돌한 기존 관리 값 계정 원본 보존
- 머신 생성 경로 충돌의 채택 불가 및 로컬 도구 경로 해소 후 재시도
- 기존 자산 디렉터리·다른 링크 충돌 시 적용 중단 및 수동 보존·이동 안내
- 기존 로그인에 대한 강제 재로그인 없음
- 임의 홈 탐색을 통한 자동 등록 없음

## 9. 셸과 CLI의 책임

- 셸 함수: 현재 선택 변경·등록 해제 후 별칭 갱신·종료 코드 보존
- CLI: 등록부·설정·기본값·백업·실행 대상 검증
- CLI 실행 실패·로그인 취소 이후에도 완료된 등록 상태의 셸 반영
- 인자의 원형 전달 및 임의 명령 문자열 `eval` 금지
- 외부 `cenv use`의 부모 셸 변경 불가 안내 및 종료 코드 2
- 설치 시 `.zshrc` 관리 구간·고정 연결점 구성
- 새 셸의 자동 로딩
- 최초부터 열려 있던 터미널에 한정한 새 탭 또는 선택적 `source`
- 계정 추가·해제·선택의 반복 `source` 요구 없음
- 셸 로딩의 네트워크·Codex 실행·설정 쓰기 없음

## 10. 배포와 설치

- 규칙·권한 정책 포함 시 명시적 확인, 비대화형 `--yes` 필수
- 개인 허용 규칙·승인 정책의 명시적 선택 없는 전파 금지
- 알려진 개인 경로·비밀 값 발견 시 내보내기 중단
- 검사만으로 개인화·비밀 값의 완전 제거 보장 금지
- 허용 목록 기반 아카이브 및 파일별 체크섬
- 배포 폴더 외부 링크·Git ignored 산출물·가상환경 제외
- 홈 경로 템플릿의 대상 홈 현지화
- 출처·버전·해시·라이선스를 통한 선택 도구 재현
- 대상 Mac의 계정별 공식 로그인·서비스 인증·앱 권한 별도 필요
- 설치 사전 의존성·기존 셸 충돌 확인 및 `--dry-run`
- 관리 구간만 갱신 및 기존 사용자 설정 보존
